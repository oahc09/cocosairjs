# ForgeAX 借鉴：Cocos AIR Review 任务清单（2026-11-28）

只借鉴可发现、可追溯、可复核的工作流，不移植 ForgeAX 源码或加运行时依赖。保留 Cocos Node / Component、WebGL 2 默认及已有 MCP。

| ID | 任务 | 通过条件 |
| --- | --- | --- |
| P0-01 | 复用 AgentSession 做本地 review CLI | doctor、inspect、capture、verify 输出版本化 JSON；浏览器结束后退出；首次复用现有 dev 启停，不新增守护进程 |
| P0-02 | 固定证据身份 | 本地源码绑定和实际浏览器 bundle 匹配；换页／换 Scene 拒绝旧观察；PNG、帧号、场景和后端同收据 |

| P2-01 | Agent 开发效率对照 | 同任务、同验收条件记录通过率、修复轮数和耗时；引擎 FPS 单独比较，不在本轮 |
