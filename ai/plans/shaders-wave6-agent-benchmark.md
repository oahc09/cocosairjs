# Wave6：精简 Agent 使用验收

2026-10-12，按用户最新指令开始 Wave6：任务已严重延迟，后续避免过度设计测试。该指令允许先开展独立 Agent Benchmark；此前 Wave5 的 SDK 字节阻塞保留，不补标为 PASS。

## 要得到的结果

判断一个没有内部答案的新 Agent，能否依据公开 Cocos AIR 文档、类型与基础示例实现视觉效果。分别记录 Engine 是否运行正确，以及 Agent 是否能独立完成。

首轮只做三个任务，每个难度一个，不增加种子、模型或重复运行矩阵：

| 任务 | 目标 |
| --- | --- |
| 简单：NoiseDissolve | 原生材质实现噪声溶解，支持进度控制、两端状态及释放 |
| 中等：Neon | 原生材质实现有管体和外晕的霓虹形状，支持厚度、强度及暂停/恢复 |
| 复杂：Glass | 原生相机与 RenderTarget 实现对子场景内容的玻璃采样，支持折射、输入直通及释放 |

## 隔离与执行

每个被测 Agent 使用新上下文及独立目录，只能读取准备好的公开资料、SDK 声明与基础示例。不能读取既有目标效果实现、私有 oracle、测试夹具、内部台账或前面 Worker 的实现会话。已知答案的 Lead 和既有 Worker 只能准备材料、独立验收，不计为被测 Agent。

准备阶段固定复制现有 SDK，不构建、安装或修改并行任务的产物。Agent 编写阶段可并行，真实浏览器检查串行。首轮以 Chromium 桌面完成首次使用验收；跨浏览器、完整 Engine 回归与性能研究另列未测，不继承旧 PASS。

先保存首次产物和首次检查结果，再允许依据实际错误修复。默认每项最多两轮修复；超出则记录未完成及原因，先交付首轮结果。记录真实耗时；token 无可用数据时标 unavailable。

## 足够判断结果的检查

- 实际 TypeScript 和 bundle 编译，浏览器启动及 shader 编译，无页面错误。
- 一张默认实际截图和一项关键状态变化；按任务检查噪声溶解两端、Neon 强度变化、Glass 输入直通。截图存在不能代替算法或管线判断。
- 使用一次真实控件，并进行一次 resize 和显式释放；核对自有资源、监听及相机/RT 解绑证据。
- 实现符合原生 SDK、单 canvas 和资源所有权要求。性能未测则明确未测，不把这轮小样本称为完整六门 Engine Gate。

只围绕实际失败增加必要验证。不新建大型合成夹具、篡改矩阵、通用 Gate 框架，不重跑 Wave1–5。

## 记录与交付

每项记录首次成功、编译与运行尝试次数、API 错误、文档查阅、人工介入、最终成功、耗时和可用 token。证据包括任务、公开资料清单、Agent 实际产物、原始命令/退出码、截图与错误日志。

最后给出三个任务的实际结果和主要失败原因，按既有九类分类。只有实际完成的隔离任务计入成功率；三项小样本不推断全体 Agent 或 SDK 的通用成功率。Agent Gate 当前为 NOT_RUN，准备材料不授予 PASS。
