结论：先核对 HDR/LDR 的光照单位及曝光，再确认真正生效的主方向光，最后逐层检查全局、灯光和模型的阴影条件。以下是冻结文档中的诊断规则，并非对当前场景的运行验收。

1. 亮度与单位：DirectionalLight.illuminance 使用 Lux（lx）；HDR 下方向光和 Ambient.skyIllum 写入时乘 camera.exposure，LDR 使用各自 LDR 标量，不再乘曝光。Point/Sphere/Spot 使用 luminance 或 luminousFlux；HDR luminousFlux 经 nt2lm(size)=4*PI*PI*size*size 换算为 luminance，再乘 exposure 和 standardLightMeterScale=10000。Point 的通量换算使用 size=1，Sphere/Spot 使用自身 size；LDR setter 直接存储 LDR 标量。因此不要把不同类型的灯、HDR 与 LDR 数值当作同一亮度刻度。Light.color 必须是 Color，分量为 0..255。来源：skills/cocosair-rendering/references/lighting-units.md（DirectionalLight illuminance、Local light luminous units、Conversion written into the UBO、Light component surface）。

2. 主方向光：默认 legacy forward 对普通 DirectionalLight 只使用 renderScene.mainLight，容量为 1；第二盏普通方向光不会增加照明，也不能当作独立补光。使用 inspectAirDirectionalLights(scene) 检查 available/unavailable、mainLight 与每盏灯 effective 的身份；它报告身份，不证明当前像素结果。方向光阴影也只取 mainLight。来源：skills/cocosair-rendering/references/lighting-units.md（Legacy forward mainLight limitation）；skills/cocosair-rendering/references/shadow-matrix.md（Support grid、Concrete silent-miss symptoms）。

3. 支持条件：主 DirectionalLight 的 Planar 沿 mainLight 方向投影到单个平面，ShadowMap 支持 fixed-area / CSM；SpotLight 不是 Planar 光源，但存在 shadowEnabled 控制的 ShadowMap 路径。PointLight 不支持阴影生成，SphereLight 没有默认阴影路径，RangedDirectionalLight 不属于此主光阴影矩阵，Ambient 不能投影阴影。不能用 Spot 的结果冒充 Point 支持。来源：skills/cocosair-rendering/references/shadow-matrix.md（Support grid、Documented workarounds）。

4. 无阴影时依次核对：全局 shadows.enabled 是否打开、模式是否为期望的 Planar 或 ShadowMap；ShadowMap 的 ShadowFlow 要求 enabled=true 且 type=ShadowType.ShadowMap。DirectionalLight.shadowEnabled 默认 false，必须打开；全局阴影默认也关闭。还要检查模型的 cast 与 receive 全部开关，模型是否有有效 bounds（没有会被方向光阴影剔除队列跳过）。确认投影物、接收物落在阴影覆盖范围；Planar 要记录接收平面、投影范围及 bias。方向光 ShadowMap 按实际模式检查 shadowFixedArea、shadowNear/shadowFar/shadowOrthoSize，或 CSM 的 csmLevel、支持条件和 shadowDistance；这些方向光字段不适用于 Point/Sphere，Spot 只暴露 shadowEnabled、shadowPcf、shadowBias、shadowNormalBias。来源：skills/cocosair-rendering/SKILL.md（Contracts、Common Mistakes）；skills/cocosair-rendering/references/shadow-matrix.md（ShadowFlow gate、DirectionalLight shadow fields、SpotLight shadow fields、Fields ignored、Concrete silent-miss symptoms）。

5. 验证边界：文档记录的主光 ShadowMap 像素证据仅对应 examples/campfire-night 的固定场景及当时指纹；Planar 当轮未得到可判定 ROI 像素变化，Spot 当轮未单独取得运行证据。字段赋值、声明或 bundle 导出均不能证明当前场景阴影正常，应在当前场景检查实际像素和投影/接收范围。来源：skills/cocosair-rendering/references/shadow-matrix.md（Documented workarounds、Bundle reachability）；skills/cocosair-rendering/SKILL.md（Contracts）。
