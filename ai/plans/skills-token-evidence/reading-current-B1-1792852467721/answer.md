先核对光照单位、HDR/LDR 分支与实际主方向光，再逐一检查阴影全局、光源及模型开关。以下结论仅来自本次冻结文档，不构成当前场景运行时 PASS。

1. 亮度与单位：DirectionalLight.illuminance 使用 Lux（lx）；HDR 默认值为 65000，HDR 写入为 illuminance × camera.exposure；LDR 使用独立的 illuminanceLDR 槽，不再乘曝光。Ambient.skyIllum 同样在 HDR 乘曝光、LDR 不乘。不要把 HDR 与 LDR 的标量直接混用。Point/Sphere/Spot 使用 luminance 或 luminousFlux；HDR 的 luminousFlux 先除以 nt2lm(size)，其中 nt2lm(size)=4×PI×PI×size²，再按 luminance × camera.exposure × standardLightMeterScale 写入，standardLightMeterScale=10000；LDR 使用自身标量。Point 的 luminousFlux 换算使用 size=1，Sphere/Spot 使用自身 size。Light.color 要传 Color 实例，组件 RGB 通道范围为 0..255。依据：[lighting-units.md](skills/cocosair-rendering/references/lighting-units.md)。

2. 有效主光：默认 legacy forward 中普通 DirectionalLight 只有一个有效主光，即 scene.renderScene.mainLight；最后激活的方向光获选，额外方向光不会叠加照明，也不会各自投射主光阴影。使用 inspectAirDirectionalLights(scene) 检查 mainLight 与 lights[].effective；若 native render scene 尚未建立，会得到 unavailable。第二盏方向光可能触发一次 AIR_W_DIRECTIONAL_LIGHT_LIMIT 警告。需要补光可考虑 Point/Sphere/Spot，而不能依赖第二个普通方向光叠加。依据：[lighting-units.md](skills/cocosair-rendering/references/lighting-units.md)、[contracts.md](skills/cocosair-rendering/references/contracts.md)。

3. 阴影支持条件：默认 WebGL2 legacy 管线中，主 DirectionalLight 的 ShadowMap 支持 fixed-area/CSM；CSM 还要求 csmSupported 且 csmLevel>1。Planar 只沿主方向光投影到一个接收平面，并非所有灯光通用。SpotLight 有 shadowEnabled 控制的 ShadowMap 路径；PointLight 不支持阴影生成，SphereLight 无默认阴影路径，RangedDirectionalLight 不属于此主阴影矩阵，Ambient 不产生阴影。不能用 Spot 的结果证明 Point 阴影受支持。依据：[shadow-matrix.md](skills/cocosair-rendering/references/shadow-matrix.md)。

4. 缺阴影应依次检查四个独立开关：scene.globals.shadows.enabled=true（默认 false）；scene.globals.shadows.type=1（ShadowMap，场景全局默认 Planar=0）；有效主方向光 shadowEnabled=true（默认 false）；投影模型 renderer.shadowCastingMode=MeshRenderer.ShadowCastingMode.ON（默认 OFF）。缺任一个可能静默无阴影、无警告。默认 bundle 没有顶层 ShadowType/PCFType/CSMLevel 导出，故 Code First 可用上述 type ordinal，不能假设能直接 import ShadowType。模型必须有有效 world bounds，否则阴影裁剪队列跳过；检查阴影接收对象/接收平面及投影范围。fixed-area 路径还应核对 shadowNear、shadowFar、shadowOrthoSize 是否覆盖投影物和接收区域；CSM 路径核对 shadowDistance、csmLevel，必要时检查 bias/normalBias。不要把这些方向光专属参数套到 Point/Sphere/Spot。依据：[contracts.md](skills/cocosair-rendering/references/contracts.md)、[quick-start.md](skills/cocosair-rendering/references/quick-start.md)、[shadow-matrix.md](skills/cocosair-rendering/references/shadow-matrix.md)、[common-mistakes.md](skills/cocosair-rendering/references/common-mistakes.md)。

5. 验证范围：文档记录的主光 ShadowMap 像素证据仅对应 campfire-night 当时固定场景与指纹；Planar 当轮没有获得可判定 ROI 像素变化，Spot 当轮没有单独运行时采样。这些与 API/声明/bundle 可达性应分开，字段写入成功也不等于阴影已显示；当前场景仍需实际浏览器像素和画面检查。依据：[shadow-matrix.md](skills/cocosair-rendering/references/shadow-matrix.md)、[cocosair-rendering/SKILL.md](skills/cocosair-rendering/SKILL.md)。
