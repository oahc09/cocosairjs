This is a subsequent revision of the blocked candidate `e6f3a2eacdbd97eaf5f9fdfa5dc74ed3ee9fb0b9`. Its previous bundle, raw evidence and [final status](FINAL.md) remain immutable historical records. This correction does not assert overall plan acceptance, rendering, generated model runs, a PR, or a release.

## Correction and original contract

The previous report classified the missing Three declaration identity too broadly as an external prerequisite. The official registry provides `@types/three@0.186.0` for the unchanged `three@0.186.1`. DefinitelyTyped aligns the major/minor version; its patch version is independent. The original plan's U06 TS4.9 legacy obligation applies to the Cocos SDK. The Agent task's public strict-consumer specification did not require Three to support Cocos legacy compilers. The first AU12 adapter incorrectly imposed that extra condition.

Sources: [the official package metadata](https://registry.npmjs.org/@types%2Fthree/0.186.0), [DefinitelyTyped's versioning policy](https://github.com/DefinitelyTyped/DefinitelyTyped#how-do-definitely-typed-package-versions-relate-to-versions-of-the-corresponding-library), the original plan U06 and section 7, and `docs/manual/typescript-dom-compatibility.md` from fixed main `b573be0741db9e2a13d38ce7e65870b97a1f5fbc`.

## Common task versus candidate extension

Original plan section 7.3 lists cache/cancellation and independent SDK consumption as separate business tasks. AU12's public specification requires isolated installed ESM/Vite, strict native types, explicit decoder deployment, DOM-free math and a single engine instance. It does not prescribe the new AirRequestPolicy or nested request property; U06 separately requires those candidate declarations to be exact.

The first revision exposed a second preparation defect: applying the complete candidate-only contract to the fixed-main control. Its raw result is retained: resolver, DOM-free math and Vite passed, but each of four compiler modes reported ten diagnostics from the absent new request API. This is an expected capability difference, not an Agent failure, infrastructure failure, or reason to modify the old package.

The explicit paired-common/1 fixture preserves the same native Cocos API checks for both archives: 21 existing negative cases and two type-only probes. Three uses its seven native cases for the same installed-consumer business task, not invented Cocos signatures. All Cocos four compiler modes remain required. The unchanged full contracts.ts and its 33 + 3 negative controls are candidate-u06-extension/1; the candidate is tested separately. Validators reject unknown, missing, or extension scopes presented as common AU12 PASS. No task denominator or business acceptance criterion is removed.
