## Frozen scheduler and native semantics

- Activation uses a detached original Node with real components, then `scene.addChild(node)` into the running original Scene. `app.run(scene)` is followed synchronously by `clock.begin()` before any awaited work. No `_activeInHierarchy`, `_enabled`, `_objFlags` or GAME_VIEW assignments create activity. Private flags are read-only observations, never written. No core scheduler method is replaced.
- `NodeActivator` queues initial callbacks. Original non-editor `invokeOnEnable` checks `comp._enabled` again after onLoad, so the first case's legal self-disable must skip the queued enable callback rather than generating an artificial disable callback.
- Original `Component.schedule` takes paused state from `Scheduler.isTargetPaused`. Original completion snapshots the actual post-callback current timer entry, then pauses/resumes it. In case two, removal of the old final timer removes its hash entry; scheduling replacement creates a current entry. The pool may reuse the same object, so this fixture intentionally does not assert pointer inequality. Public isScheduled and pause queries plus actual callback non-execution establish semantics.
- Original `CallbackTimer.update` initializes elapsed=-1 to zero on its first eligible scheduler tick without invoking its callback. A zero-interval timer next fires on the second eligible tick. A zero-delay scheduleOnce uses repeat=0 and is removed after one trigger. Counts refer to these exact bounded original frames, never wall-clock sleeps. The fixture does not claim that every generic timer must fire on the first frame.
- Director starts components, updates components, updates its registered systems (including the original Scheduler), then runs PhysicsSystem.postUpdate. Every awaited frame records clock receipt, Director total-frame delta and real native step-index delta. With a fresh unstepped app, fixedTimeStep=1/60, maxSubSteps=1, autoSimulation=true and one DT per frame, exactly one native step is required. No accumulator reset, direct PhysicsSystem.step, disabled 2D system, alternative clock or scene tick is used.
- Real target motion uses fixed identity orientation and zero damping. An independent float32 four-substep calculation reads the actual native localCenter and predicts velocity and origin; returned native plan, native state, Node writeback and following idle zero are compared. Restored N4 reports localCenter zero. This is not nonzero-COM qualification.
- Only test-local RigidBody subclass lifecycle and timer callbacks extend behavior, and each lifecycle calls its original super. No mock observer or forged adapter is installed. The unchanged transparent preload forwards actual facade methods and records real transition before/after states, direct input bytes, outputs and observation errors.
