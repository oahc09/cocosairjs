# Native and public Capsule source contract

Status: source candidate, no fresh build or Capsule execution claimed. Formal 2128 cells and nine Gates remain NOT_RUN. Existing historical failures and N4/query results are unchanged and do not qualify this new source.

The existing mass-shape ABI adds kind 2, seven float32 inputs: center.xyz, radius, halfSegment, direction, density. Direction is exact 0/X, 1/Y or 2/Z at the native/facade boundary. Radius and density are positive; halfSegment is nonnegative and equals Cocos cylinderHeight / 2. Total height is cylinderHeight + 2 * radius. No new export or ABI version is introduced; a new exact schema hash is required and old modules are rejected.

Exactly zero segment explicitly constructs a native sphere with sphere mass. Positive segments never fall back to a sphere: actual float32 endpoint squared distance at or below the pinned linear-slop squared (0.005m) rejects before creation. Nonfinite endpoints, derived mass/COM/inertia, transformed AABB and extents reject. Requested total mass uses the existing solid-first plan with sensor-only fallback; targetMass 0 preserves the core density-based semantics with added-first finite preflight.

Cocos CapsuleCollider uses its real selector and ICapsuleShape lifecycle. Cylinder height scales by the absolute axis scale, radius by the maximum of the two perpendicular absolute scales, and center by signed component scale. Existing positive-scale, hierarchy and shear admission remains unchanged; this does not enable negative scale or arbitrary parent shears. Existing public setter normalization remains for Cocos compatibility. Box3D-only setters ask the adapter to accept the candidate before committing public fields, under the existing mutation owner guard.

New shape creation retains the old shape until success. Only the reviewed Capsule path can treat a pre-native failure or known INVALID/ARGUMENT/UNSUPPORTED/LOCKED return as not-mutated. Creation failure, unknown status, native trap, and post-native JavaScript readback failure are not rollback evidence. Existing Box/Sphere fault handling is not relaxed. Public caches, logical-collider mapping and old token remain unchanged on a proven no-write refusal; uncertain native progress faults the owning world.

Native source supports true Capsule mass, motion/command admission and a 100-line surface wireframe (two end rings, four cylinder generators, four hemisphere arcs). This is not public debug drawing or Capsule contact-snapshot qualification. Hull/mesh/compound/joints are not implemented by this change. EX01 scene rendering, placement, drag extension, new ESM/DTS and browser validation remain pending.

The new native capsule_contract checks three axes, analytic mass/inertia/angular impulse, actual native type and endpoints, zero sphere, slop and float32-degeneration refusals without writes, command/motion/type changes, sensor fallback, debug allocation failure and 128 lifetimes. New public CPU controls are explicitly pure/injected controls, not physics evidence. Build runner and audit retain existing regressions and add this real native fixture for host and WASM. Actual public Cocos + newly built WASM evidence must be recorded separately; no old N4 result may be reused.
